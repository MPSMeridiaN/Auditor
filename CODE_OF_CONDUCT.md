# Code of Conduct

## Our standard

We want this project to be useful, technically rigorous, and welcoming. All
contributors are expected to communicate with respect, assume good intent,
give actionable feedback, and focus criticism on the work rather than people.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
disruption, doxxing, and publishing private information without consent.

## Enforcement

Report a concern privately through the contact method listed in
[SECURITY.md](SECURITY.md), or ask a repository maintainer to handle it. Reports
will be reviewed promptly and kept as confidential as practical. Maintainers
may remove comments, close discussions, or restrict participation when needed
to protect the community.

This code of conduct applies in project spaces and wherever someone is
representing the project.
